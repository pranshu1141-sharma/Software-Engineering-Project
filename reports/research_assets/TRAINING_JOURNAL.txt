AI HEALTHCARE MODEL DEVELOPMENT AND TRAINING JOURNAL


This is an experiment journal, not a published academic journal article.
Machine-generated timestamped entries below record actual execution.
The initial code and execution are AI-assisted; human contribution ownership
is assigned separately in TWO_PERSON_WORK_SPLIT.txt.

WHAT MAKES A MODEL TRAINED?con
- Logistic Regression: the optimizer learns class weights from training-text
  features and labels. C is selected using validation macro-F1.
- DistilBERT: pretrained language weights and a newly initialized specialty
  classification layer are updated by backpropagation using labeled examples,
  weighted cross-entropy loss and AdamW. Best epoch uses validation macro-F1.
- CatBoost: successive regression trees learn errors in wait estimates from
  simulated queue features and observed-in-simulation wait targets.
- Fitted models are saved and reloaded to check that predictions persist.

DATA AND METHODS
Text source: public Gretel symptom_to_diagnosis (LLM-rewritten, 22 conditions).
Source files and pretrained DistilBERT are pinned to downloaded revisions;
download_manifest.json files contain file checksums and timestamps.
Exact condition names are removed from input text. Negation words are retained.
Duplicate audit uses character TF-IDF similarity >= 0.90 and connected groups.
Publisher test examples stay in the test partition; related training rows are
excluded. Remaining training data is split into grouped training/validation.
Classifiers fit text vectorizers on the training partition only.
Specialty labels are unreviewed condition-to-department proxies (9 classes).
Queue data is locally simulated; chronological whole-session evaluation.

EVALUATION
Classification: accuracy, macro-F1, top-three accuracy, per-class report,
confusion matrix and row-level test predictions.
Queue: MAE and RMSE in minutes, compared with arithmetic baseline.
Model scores are uncalibrated and not clinical probabilities.
No real-world, clinical, subgroup or external validation is claimed.

SETUP NOTE
An initial package-resolution attempt was cancelled before installation to
install the NVIDIA CUDA build of PyTorch first. No training failed in that step.
Dependencies and checkpoints are stored inside healthcare-ai, separate from
the existing J.A.R.V.I.S environment.
