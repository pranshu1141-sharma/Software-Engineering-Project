DATA
Text: gretelai/symptom_to_diagnosis on Hugging Face.
1,065 English descriptions; 22 publisher condition labels.
853 publisher training rows, 212 publisher test rows before cleaning.
Publisher describes adaptation from Symptom2Disease using an LLM.
Publisher declares Apache-2.0. Original card and revision are downloaded.
This is a small educational benchmark, not clinically validated patient data.

Specialty labels: config/specialty_mapping.json contains author-defined,
UNREVIEWED mappings from condition names to 9 department labels. No claim of
professional review. They are proxy labels for pipeline development.

Queue: 90 days x 3 simulated departments x 45 arrivals = 12,150 records.
Generated using a documented first-come-first-served simulator and seed 42.
No real hospital records have been obtained. Simulation scores are not real-world scores.

DEVELOPMENT / VERIFICATION TOOLS
FastAPI + uvicorn: local research API for saved models.
pydantic: request validation (installed by FastAPI).
pytest + httpx: input-validation, leakage and saved-model integration tests.
Git: source tracking; no commits or publication performed automatically.
PowerShell: repeatable local setup and execution scripts.
huggingface-hub, accelerate: support libraries listed for installation; the initial training
loop uses native PyTorch, and the downloader uses Python urllib.
datasets: not required in the initial implementation; JSONL is read with pandas.

MODEL DOWNLOADS
distilbert/distilbert-base-uncased, Apache-2.0: model.safetensors, tokenizer,
configuration, README and LICENSE. No remote custom code is executed.
Logistic Regression and CatBoost are fitted locally, so there are no pretrained
weights to download for those models.
